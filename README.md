# Perp DEX Airdrop Tracker

Live site: **https://dondaniel83.github.io/Perp-Airdrop-Calculator/**

Browser tool to track points, PNL, and estimated net airdrop value across perpetual DEXs. Everything runs in the page — no server, no login. Your numbers stay in `localStorage`.

## GitHub Pages

This is a static site on purpose. GitHub Pages can host HTML, CSS, JS, and images. It cannot host a backend (Node, PHP, a database). A single `index.html` plus logos is the simplest setup that stays public and free.

To publish a change: commit to `main`. Pages rebuilds from the repo root.

## How to use

1. Open the live site
2. Fill **Points** and **PNL** per venue
3. Tweak pool / % airdrop / FDV if your estimate differs
4. Export JSON if you want a backup; import to restore it

Estimates are a rough guide and can go stale. DYOR. Leverage trading is high risk.
