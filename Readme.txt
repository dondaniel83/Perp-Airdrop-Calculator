# Perp DEX Airdrop Tracker

The ultimate browser-based tool to track points, PNL, and estimate net airdrop rewards across major perpetual DEXs.

### Features
- Real-time net airdrop calculations (includes full PNL: gains + losses)
- Local storage – your data stays in your browser
- One-click reset to default values
- Clean, responsive table layout
- Total Expected Net Profit overview

### How to Use
1. Adjust Points Pool, % Airdrop, FDV, Points, and PNL for each project
2. Watch the net values update instantly
3. Use the "Trade" links if you want to support the tool (referral links – no extra cost to you 😎)
4. Share your expected results if you want via X.
